# VoltRelay Battery Swapping Analytics

## Project Overview

An end-to-end data analytics project focused on analyzing
battery swapping operations, station performance, battery
health, and rider retention using Python, SQL, DuckDB,
Pandas, and Jupyter Notebook.

## Objectives

- Analyze completed swaps, revenue, and network growth.
- Identify station and city-level operational issues.
- Investigate swap failures and queue abandonment.
- Analyze battery health, degradation, and retirement.
- Understand rider activity, retention, and inactivity.
- Develop data-driven operational recommendations.

## Tech Stack

- Python
- Pandas and NumPy
- DuckDB and SQL
- Matplotlib, Seaborn, and Plotly
- Jupyter Notebook

## Project Structure

- `src/` - Data processing and analytics modules
- `notebooks/` - Exploratory analysis and visualizations
- `data/` - Local datasets and analysis outputs
